# Sky Raiders 8-Bit

Shooter aéreo arcade original com visual 8-bit/pixel-art.

## Jogar
Abra `index.html`.

## Controles
- WASD ou setas: mover
- Espaço: atirar
- P: pausar
- Enter: reiniciar

Inclui 6 biomas, fases progressivas, inimigos, tiros, explosões, vidas e pontuação.

## GitHub Pages
Envie os arquivos para um repositório e ative GitHub Pages usando a branch principal e a pasta `/root`.

## Mobile
Compatível com celular e tablet, com controles virtuais de esquerda, direita e tiro. Funciona em orientação horizontal; em telas estreitas há suporte automático para rotação.
