# 🛩️ Super River Raid 16-Bit Edition

Uma releitura moderna e retrô em estilo **16-Bit** do lendário jogo **River Raid** (Atari 2600), totalmente desenvolvida em HTML5 Canvas, JavaScript Vanilla e Web Audio API.

## 🎮 Como Jogar

Você controla um caça em missão pelo rio inimigo. Seu objetivo é ir o mais longe possível destruindo inimigos e gerenciando seu nível de combustível.

### Controles:
* **Setas (Esquerda / Direita)** ou **A / D**: Mover a aeronave.
* **Seta para Cima / W**: Acelerar (gasta mais combustível).
* **Seta para Baixo / S**: Desacelerar.
* **Barra de Espaço**: Atirar / Iniciar o Jogo.

---

## ⚡ Recursos do Projeto
* 🎯 **Zero dependências externas**: Não requer instalação de pacotes (Node.js, npm, etc).
* 🔊 **Áudio Retro 8/16-bit**: Efeitos sonoros gerados dinamicamente via sintese de áudio no navegador (`Web Audio API`).
* 🎨 **Gráficos Pixel-Art**: Renderização via Canvas API estilizada como consoles clássicos da era 16-bit.
* ⛽ **Mecânicas Clássicas**: Gestão de combustível, colisão com margens do rio e inimigos dinâmicos.
* 🏆 **High Score Local**: A maior pontuação fica salva no seu navegador (`localStorage`).
